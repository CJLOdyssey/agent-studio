# 管理工作台 8 个 Tab · 右侧内容区线框草图（2026-08-01）

> 管理工作台导航左侧边栏，右侧内容区按 tab 切换。本草图展示每个 tab 的内容区：**工具栏（搜索 + 分类筛选 + 状态筛选 + 操作按钮）** + **表格列**。
> 依据实际代码核实（各 `*Management.tsx`），非猜测。

**通用说明**：
- 分类筛选大部分是**动态去重**（`Array.from(new Set(items.map(category)))`），首项固定「全部分类/全部类型」
- 状态筛选是固定枚举，首项「全部状态」
- 批量删除按钮：勾选行后出现
- 每行右侧「⋮」操作菜单（编辑/版本历史/测试/删除）

## 汇总对照

| Tab | 搜索 | 全部分类 | 全部状态 | 操作按钮 | 特有 |
|-----|------|---------|---------|---------|------|
| 提示词 | ✅ | ✅ 动态 | ✅ active/draft/archived | 批量删除+新建 | — |
| 输出约束 | ✅ | ✅ 动态 | ✅ active/draft/archived | 批量删除+新建 | 内容列 |
| 工具 | ✅ | ✅ 动态 | ✅ active/disabled | 批量删除+新建 | 内置标记 |
| MCP | ✅ | ❌ 无分类筛选 | ✅ connected/disconnected/error | 批量删除+新建 | 类型列+测试 |
| Skills | ✅ | ✅ 动态 | ✅ installed/available | 批量删除+新建 | **导入SKILL.md** |
| Agent | ✅ | ❌ 无分类筛选 | ✅ running/stopped/error | 批量删除+新建 | 运行中禁删 |
| 团队 | ✅ | ✅ 动态 | ✅ active/disabled | 批量删除+新建 | 管理成员 |
| 工作流 | ❌ 团队下拉 | ❌ | ❌ | 测试/保存/删除 | **图编辑器** |

> 分类筛选为动态去重（非固定枚举）：数据里有啥分类就显示啥，首项恒为「全部」。
> 工作流是唯一非列表型 tab——以团队下拉为入口进入 ReactFlow 图编辑器。
