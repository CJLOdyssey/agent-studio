- [ ] **Step 1: pyproject.toml [tool.mutmut] 段加注释**

```toml
[tool.mutmut]
# CI 硬门禁运行范围：core/infra/ + services/（纯逻辑、单测覆盖）。
# 引擎（graph/workflow/checkpoint）依赖 langgraph 重 mock，逐步扩量（见 2026-08-05 plan P5）。
paths_to_mutate = ["backend/src/"]
exclude_paths = [
    "backend/system_team/",
    "backend/thinking_tree/",
    "backend/checkpoint/",
    "backend/graph/",
]
test_runner = "PYTHONPATH=backend/src python3 -m pytest -x --no-header -q"
score_threshold = 60
```

- [ ] **Step 2: 创建 `.github/workflows/mutmut.yml`**

```yaml
name: Mutation Testing (mutmut)

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

permissions:
  contents: read

jobs:
  mutmut:
    name: "Backend: Mutation Score"
    runs-on: ubuntu-latest
    timeout-minutes: 30
    container:
      image: ghcr.io/cjlodyssey/agent-studio/ci-runner:latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install mutmut --quiet
      - name: Run mutation tests (core/infra + services)
        run: |
          mutmut run \
            --paths-to-mutate backend/src/core/infra backend/src/services \
            --runner "PYTHONPATH=backend/src python3 -m pytest -x --no-header -q" 2>&1 | tail -40
      - name: Enforce score threshold (60%)
        run: |
          score=$(mutmut results | grep -oP 'Mutation score: \K[0-9.]+' || echo 0)
          echo "Mutation score: ${score}%"
          python3 - "$score" <<'PY'
          import sys
          threshold = 60.0
          score = float(sys.argv[1])
          if score < threshold:
              print(f"❌ Mutation score {score}% below threshold {threshold}%")
              sys.exit(1)
          print(f"✅ Mutation score {score}% >= {threshold}%")
          PY
```
