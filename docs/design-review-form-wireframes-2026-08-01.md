## 8. 工作流编辑器

### 优化前
```
┌────────────────────────────────────────────┐
│ [选择团队 ▾]              (仅下拉入口)      │
├────────────────────────────────────────────┤
│ [工作流名称______] [最大轮次: 3] [保存]     │
│ [+AgentA] [+AgentB] [+AgentC]              │
│                                            │
│    ┌─────────┐       ┌─────────┐           │
│    │ AgentA  │──────▶│ AgentB  │           │
│    │ [生成 ▾] │       │ [审查 ▾] │           │
│    └─────────┘       └─────────┘           │
│      (随机位置, id=name, 无入口/出口/分支)  │
│      (无执行/测试按钮)                     │
└────────────────────────────────────────────┘
```

### 优化后
```
┌────────────────────────────────────────────────┐
│ [工作流列表] [新建]      (独立管理入口)          │
├────────────────────────────────────────────────┤
│ [名称________] [轮次: 3] [▶ 运行] [保存] [删除] │
│ [+AgentA] [+AgentB]  (agentConfigId 自动布局)   │
│                                                  │
│  ┌────────┐   ┌─────────┐   ┌─────────┐          │
│  │ START  │──▶│ AgentA  │──▶│ AgentB  │          │
│  │ 入口   │   │ [生成 ▾] │   │ [审查 ▾] │          │
│  └────────┘   └────┬────┘   └────┬────┘          │
│                    │ if/else 分支 │                │
│              ┌─────▼─────┐       │                │
│              │ END/Output◀───────┘                │
│              └───────────┘                        │
│  (节点面板: strategy+objective+输出格式)          │
│  (环路检测 ✓ / dirty 检测 ✓)                     │
└────────────────────────────────────────────────────┘
```
> 加：独立入口、显式 START/END、分支配置、运行测试、节点契约面板。

## 改动量汇总

| 表单 | 线框差异要点 | 改动量 |
|------|-------------|--------|
| Skill | 删版本/状态/输出约束、拆工具/MCP | 中 |
| MCP | 状态换开关、env 结构化、删描述/版本 | 大 |
| 工具 | 加 method/headers、描述必填、删版本 | 中 |
| 提示词 | 加描述/参数化、删版本/模型 | 中 |
| 输出约束 | 删分类/状态、建消费链 | 小 |
| Agent | 加角色、输出约束独立、删版本 | 中 |
| 团队 | 去重/枚举/workflow 引导 | 小 |
| 工作流 | 加 START/END/分支/测试/契约面板 | **最大** |
