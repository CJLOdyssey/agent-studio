## ⚠️ 关键行业策略（本次修正的核心，来自 antd/ProTable/Dify）

**优化后不是「复制优化前」，而是按行业策略重新设计三块展开：**

### 策略 1：操作列 —— 高频操作行内暴露，低频进 ⋮（antd 官方模式）

antd Table/ProTable 官方 demo（`render: () => [<a>编辑</a>, <a>删除</a>]`）的标准是**行内直接放高频操作按钮**，不是全部藏进下拉。
- **高频**（编辑、删除）→ 行内按钮直接可见，减少点击层级
- **低频**（版本历史、管理成员）→ 进 ⋮ 下拉
- **本项目现状**：所有操作（含高频的编辑）全藏 ⋮ —— **违反 antd 操作列规范，这是最大的优化点**

### 策略 2：列筛选 —— antd 原生在列头，ProTable 在工具栏 search

- antd Table：`filters` 内嵌在列头（点击列头筛选图标）
- ProTable：search 区 Select
- **本项目**：工具栏 Select —— 符合 ProTable 模式，**保留**（不改成列头内嵌）

### 策略 3：状态筛选 —— antd `filterMultiple` 支持多选

- antd `filterMultiple: true` 允许勾选多个状态
- **本项目**：单选 Select —— 可改进为多选（可选）

## 修正记录（v1→v4 教训）

| 版本 | 错误 | 纠正依据 |
|------|------|---------|
| v1 | 漏画底部 + 操作菜单 | v2 补全 |
| v2 | 断言「缺计数」 | **WstaPagination 已实现**「共 N 条」 |
| v2 | 「列设置/全屏是标配」 | **grep Dify 0 结果**——非标配，已从建议移除 |
| v3 | Skill 状态「可用」 | 代码核实 `available='未安装'` |
| v3 | Output 状态默认「已发布」 | 代码核实 `EMPTY_FORM.status='draft'` |
| v4 | **优化后操作区「原样复制 + 标不变」**——没按行业策略重设计 | antd/ProTable 官方 demo `render: () => [<a>编辑</a>, <a>删除</a>]`：**高频操作行内暴露，低频进 ⋮**。已把 8 tab 操作区改为「行内高频 + ⋮低频」 |
| v5 | **只改操作列、未审内容列**——版本列（agent/tool/mcp/skill）保留、时间列缺失 | 内容区域列评审（2026-08-02）：n8n/Dify 源码实测竞品 **0/2 无版本列、2/2 有时间列**；form 级评审版本 0/4 源支持、90% 填 v1.0.0。已 ✘ 版本列 / ➕ 更新时间列（6 表）/ ✎ 名称截断（7 表） |

> **v4 自我批判**：用户指出「你只是听了我的话就全改了，没参考行业策略」——v3 补展开时把优化前原样复制到优化后，是形式补全非设计。v4 基于 antd Table/ProTable 官方模式重做操作列：编辑/删除/测试/管理成员等高频操作**行内直接可见**，版本历史等低频进 ⋮。

## 结论（经验证的真实差距）

| 项 | 必要 | 依据 |
|----|------|------|
| **操作列改行内（8 tab）** | ✅ P0 | antd/ProTable 官方 `render: [<a>编辑</a>,<a>删除</a>]`——高频行内是标准，本项目全藏 ⋮ 违反规范 |
| 工作流列表页 | ✅ P0 | n8n/Dify 均有，本项目无 |
| Agent 团队筛选 | ✅ P1 | 列表混杂所有团队 |
| MCP 类型筛选 | ✅ P1 | 缺分类筛选 |
| 团队工作流列 | ✅ P1 | 对齐「团队需 workflow」语义 |
| **版本列移除（agent/tool/mcp/skill）** | ✅ P1 | 竞品 0/2 无版本列 + form 评审 0/4 源（v5 新增） |
| **更新时间列（6 表）** | ✅ P1 | 竞品 2/2 均有 + v4 已设计未落地（v5 新增） |
| **名称列统一截断** | ⚠️ P2 | 7 表均无截断，Dify truncate+Tooltip（v5 新增） |
| **分类 tag 视觉统一** | ⚠️ P2 | indigo/accent/动态色三种并存（v5 新增） |
| **team 创建时间格式化** | ⚠️ P2 | font-mono 原串直出（v5 新增） |
| 表头排序 | ⚠️ 可选 | 数据量小时价值低 |
| 刷新按钮 | ⚠️ 可选 | 数据变化不频繁 |
| 状态筛选多选 | ⚠️ 可选 | antd `filterMultiple` 支持，本项目单选 |
| 列设置/全屏 | ❌ 不做 | n8n/Dify 源码实测均无；有列设置的是通用表格组件（ProTable/MUI DataGrid）非后台标配；本项目 ≤7 列全相关，无裁剪空间 |
